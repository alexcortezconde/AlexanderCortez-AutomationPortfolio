report_problem

Problem

The team at Go2Networks manually browsed multiple websites to collect data from HTML tables, then copied and formatted everything into Excel reports. The process took ~40 minutes and had to be repeated regularly, with inconsistent formatting and risk of human error.

build

Solution

Built an Automation Anywhere bot that opens the target web pages, extracts all rows from HTML tables using web scraping, maps the data into a pre-formatted Excel template, and saves the file automatically to the shared drive.

emoji_events

Result

Execution time reduced from 40 minutes to 6 minutes (85% reduction). 60+ reports automated over the project lifespan. Consistent formatting and zero manual effort required after deployment.
