Problem

The automation team's shared inbox receives a high volume of mixed messages — bot failure alerts, status updates, stakeholder requests, and noise — with no classification system, causing delayed responses and missed zombie bot incidents.

build

Solution

An agentic pipeline using UiPath Maestro where a UiPath bot reads incoming emails, passes them to an AI agent for intent classification, logs structured data to SharePoint, surfaces insights in Power BI, and triggers HITL escalation for ambiguous cases.

emoji_events

Result

Structured email classification with automated zombie bot detection, full auditability in SharePoint, real-time visibility in Power BI, and a HITL escalation channel for edge cases — targeting near-zero manual triage. (Pending PRD.)
