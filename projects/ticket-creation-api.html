report_problem

Problem

Bosch's support team was manually creating CRM tickets for each incoming technical request — a repetitive 30+ minute process per batch that delayed response times and created bottlenecks when request volumes spiked.

build

Solution

Designed an AA A360 bot integrated with a Catalytic form and webhook trigger. On form submission, the webhook fires the bot, which reads structured request data, applies decision-tree logic to determine priority and routing, calls the CRM REST API, and logs confirmation to Excel.

emoji_events

Result

Ticket creation time reduced by 80%. 1,000+ tickets processed without manual intervention. The architecture became the standard template for 3 additional bots in the same workflow.
