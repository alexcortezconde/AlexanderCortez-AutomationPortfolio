report_problem

Problem

Bosch plant operators were manually transferring order data from a .NET web portal into SAP ERP — a 1-hour process per cycle that ran up to 15 times daily, creating a massive operational bottleneck and limiting the team's capacity for higher-value work.

build

Solution

Built an AA A360 bot that reads pending orders from the .NET portal, navigates SAP's transaction interface, enters each order's data, confirms the load, and writes an audit entry. Runs on a time trigger with no human dependency — 24/7.

emoji_events

Result

Processing time reduced from 1 hour to 8 minutes per cycle (87% reduction). 15 automated cycles per day. Continuous 24/7 operation. Delivered through 3 iterative versions with progressive stability improvements.
