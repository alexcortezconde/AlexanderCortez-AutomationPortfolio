terminal Project Overview

Legacy financial reporting at the enterprise level often suffers from manual data retrieval bottlenecks. This project aimed to automate the end-to-end extraction of mission-critical data from SAP ERP and orchestrate its delivery into a cloud-native AWS S3 data lake.

By eliminating manual spreadsheet exports and FTP transfers, we established a high-integrity pipeline that feeds downstream AI models with real-time operational metrics.

s3_orchestrator.py 
import boto3
from botocore.exceptions import NoCredentialsError

def upload_to_s3(file_name, bucket, object_name=None):
    """Upload SAP Extract to AWS S3 Bucket"""
    s3_client = boto3.client('s3')
    try:
        response = s3_client.upload_file(file_name, bucket, object_name or file_name)
        return True
    except FileNotFoundError:
        print("The file was not found")
        return False
    except NoCredentialsError:
        print("Credentials not available")
        return False
