# Portafolio — The Kinetic Engineer

Portafolio profesional para un ingeniero de RPA / IA. Construido con HTML5 semántico y Tailwind CSS v4 (CDN), sin frameworks JavaScript.

## Estructura

```
├── index.html               # Página principal / Hero
├── projects.html            # Galería de proyectos RPA
├── experience.html          # Trayectoria y experiencia
├── contact.html             # Contacto y tech stack
├── projects/
│   └── sap-automation.html  # Caso de estudio: SAP Data Extraction
├── assets/
│   └── screenshots/         # Capturas de pantalla de cada sección
├── docs/
│   └── DESIGN.md            # Sistema de diseño Synthetix Automata
└── README.md
```

## Tech Stack

- **HTML5** — estructura semántica
- **Tailwind CSS v4** — via CDN (JIT)
- **Google Fonts** — Space Grotesk + Inter
- **Material Symbols** — iconografía

## Design System

Ver [`docs/DESIGN.md`](docs/DESIGN.md) para la guía de estilos, paleta de colores, tipografía y componentes del sistema "Synthetix Automata".
